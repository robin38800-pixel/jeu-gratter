# Grand Prix d'anniversaire — cartes à gratter F1

Site statique (HTML/CSS/JS, aucune dépendance). Ouvre `index.html` ou publie avec GitHub Pages.

- **Tout se personnalise dans `config.js`** : prénom, date, les 3 F1 (nom, écurie, couleur, image), textes, blagues, probabilités.
- Les images éventuelles vont dans `images/` (ex. `image: "images/ferrari.jpg"`).
- Le tirage est fait une fois puis gardé sur le téléphone (recharger la page ne relance pas les cartes).
- Pour rejouer pendant les tests : ajoute `?reset` à l'adresse.
